# 🎬 Movie Box Bot (Updated)

টেলিগ্রাম মুভি বট + Web App — অ্যাড মনিটাইজেশন (Adsterra + Monetag), ৩-বাটন আপলোড সিস্টেম এবং ব্রডকাস্ট ডিপ-লিংক সহ আপডেটেড ভার্সন।

## 🆕 এই আপডেটে যা যা নতুন

### ১) 💰 অ্যাড সিস্টেম (Adsterra + Monetag)
- **Direct Link রোটেশন:** আপনার দেওয়া ৩টি ডাইরেক্ট লিংক (Adsterra ×২ + Monetag ×১) বট প্রথমবার চালু হলেই **অটোমেটিক DB-তে বসে যায়** (`seed_default_ads`)। ইউজার প্রতি ডাউনলোডে লিংকগুলো **পালা করে (rotation)** খোলে — সব নেটওয়ার্কে ট্রাফিক যায়, CPM বেশি হয়।
- **300x250 Banner Ad:** আপনার ব্যানার স্ক্রিপ্ট (bicea.org) ওয়েব অ্যাপের **Home পেজে** এবং **অ্যাড মোডালের ভেতরে** বসানো হয়েছে — অ্যাপ খুললেই ইমপ্রেশন গোনা হয়, ইউজারকে কিছু করতে হয় না (একদম ইউজার-ফ্রেন্ডলি ইনকাম)।
- **Multi-Ad Rounds:** `/setadcount 2` দিলে প্রতি আনলকে ২টি অ্যাড (রাউন্ড বাই রাউন্ড) দেখাবে → ইনকাম দ্বিগুণ। ডিফল্ট ১টি (ইউজার-ফ্রেন্ডলি)।
- **Countdown Timer:** অ্যাড ভেরিফাই বাটনে লাইভ কাউন্টডাউন (`⏳ অপেক্ষা করুন 7s`) — ইউজার বুঝবে কতক্ষণ বাকি, বিরক্ত হবে না।
- **VIP = No Ad:** VIP ইউজার সরাসরি ফাইল পায় → VIP বিক্রির মোটিভেশন বাড়ে।
- **18+ আলাদা লিংক পুল:** `/addadultlink` দিয়ে ১৮+ কনটেন্টের জন্য আলাদা হাই-CPM লিংক দিতে পারবেন।

### ২) 📝 ৩-বাটন আপলোড সিস্টেম
মুভি আপলোড শেষে (ক্যাটাগরি সিলেক্টের পর) এখন ৩টি বাটন:

| বাটন | কী হবে |
| --- | --- |
| 📝 **Log Only (No Broadcast)** (সবার উপরে, নতুন) | DB-তে মুভি যুক্ত + লগ চ্যানেলে পোস্ট — **ব্রডকাস্ট হবে না** |
| 🚀 **New Movie (Broadcast & Log)** | DB + লগ পোস্ট + **সব ইউজারকে নোটিফিকেশন** (আগের মতো) |
| ➕ **Add File Only (No Broadcast)** | শুধু DB/ওয়েব অ্যাপে যুক্ত — লগ বা ব্রডকাস্ট কিছুই হবে না |

### ৩) 👀 ভিউ কম হওয়ার সমস্যার ফিক্স
- **ডিপ-লিংক:** ব্রডকাস্ট/লগ পোস্টের **Watch Now** বাটনে এখন `?open=<movie_id>` থাকে — ইউজার বাটন চাপলে ওয়েব অ্যাপ খুলে **সরাসরি ওই মুভির ডাউনলোড পপ-আপ** দেখাবে। আগে ইউজারকে অ্যাপ খুলে নিজে মুভি খুঁজতে হতো — এখানেই সবচেয়ে বেশি ইউজার হারিয়ে যেত।
- **ব্রডকাস্ট অটো-ডিলিট এখন আপনার হাতে:** আগে ব্রডকাস্ট মেসেজ **২৪ ঘণ্টায় অটো ডিলিট** হয়ে যেত — পরে টেলিগ্রাম খোলা ইউজার কিছুই দেখতে পারত না। এখন ডিফল্ট **৭২ ঘণ্টা**, `/setbcastdel 0` দিলে কখনোই ডিলিট হবে না।
- **ফাঁকা অ্যাড বাগ ফিক্স:** আগে DB-তে অ্যাড লিংক না থাকলে ইউজার "বিজ্ঞাপন খুলুন" চেপেও কিছু না খুলে ১০ সেকেন্ড অপেক্ষা করে ফাইল পেয়ে যেত — অর্থাৎ **০ ইমপ্রেশনে আনলক**। এখন ডিফল্ট লিংক অটো-সিড হয়, তাই এই লস আর নেই।

### ৪) 🛠️ নতুন অ্যাডমিন কমান্ড
| কমান্ড | কাজ |
| --- | --- |
| `/ads` | সব অ্যাড সেটিংস + লিংক লিস্ট দেখায় |
| `/addlink <url>` | সাধারণ ডাইরেক্ট লিংক যোগ |
| `/dellink <url>` | ডাইরেক্ট লিংক মুছে ফেলা |
| `/addadultlink <url>` | ১৮+ লিংক যোগ |
| `/setadcount <n>` | প্রতি আনলকে কতগুলো অ্যাড (ডিফল্ট ১, CPM বাড়াতে ২ দিন) |
| `/setadwait <sec>` | প্রতি অ্যাডে অপেক্ষার সময় (সর্বনিন্ম ৫ সেকেন্ড, ডিফল্ট ১০) |
| `/setbcastdel <hours>` | ব্রডকাস্ট মেসেজ কত ঘণ্টা পর ডিলিট হবে (০ = কখনো না) |
| `/settime <min>` | ডেলিভারি করা ফাইল কত মিনিটে ডিলিট হবে (সিকিউরিটি) |
| `/protect` | ফরোয়ার্ড প্রোটেকশন অন/অফ |
| `/settg <url>` | মেইন চ্যানেল লিংক সেট |
| `/addvip <id> <days>` | ইউজারকে VIP |
| `/stats` | ইউজার/VIP/মুভি স্ট্যাট |
| `/cast` | ম্যানুয়াল ব্রডকাস্ট (যেকোনো কনটেন্ট) |
| `/cancel` | চলমান প্রসেস বাতিল |

## 🚀 ডেপ্লয় (Render)

**Environment Variables:**
| Key | Value |
| --- | --- |
| `BOT_TOKEN` | বট টোকেন (@BotFather) |
| `MONGO_URI` | MongoDB কানেকশন স্ট্রিং |
| `ADMIN_ID` | আপনার টেলিগ্রাম আইডি |
| `APP_URL` | ওয়েব অ্যাপের HTTPS লিংক (ডিপ-লিংকের জন্য অবশ্যই দরকার) |
| `ADMIN_PASS` | ওয়েব প্যানেল পাসওয়ার্ড (`/panel`) |
| `CHANNEL_ID` / `LOG_CHANNEL_ID` | চ্যানেল/লগ আইডি |

লোকাল রান: `pip install -r requirements.txt && python main.py`

## 💡 CPM ও ইনকাম বাড়ানোর টিপস (১, ২, ৩)

1. **রোটেশন চালু রাখুন** — Adsterra + Monetag একসাথে: যে নেটওয়ার্ক সেদিন বেশি CPM দেয়, সেটাই বেশি ইমপ্রেশন পাবে নিজে থেকেই। মাঝে মাঝে `/ads` দিয়ে দেখুন কোন লিংক ডেড — ডেড লিংক হলে `/dellink` করে নতুন লিংক `/addlink` করুন।
2. **প্রতি আনলকে ১টি অ্যাড + ১০ সেকেন্ড** হলো সবচেয়ে ভালো ব্যালান্স। ইনকাম বাড়াতে চাইলে `/setadcount 2` করুন, তবে রিটেনশন কমতে পারে — সপ্তাহে একবার করে টেস্ট করুন।
3. **ব্রডকাস্ট দিন পিক টাইমে** (রাত ৮টা–১১টা, বাংলাদেশ সময়) — এই সময় নোটিফিকেশন দেখার হার সবচেয়ে বেশি। দিনে ১–২টার বেশি ব্রডকাস্ট দিলে ইউজার বট মিউট করে ফেলে।
4. **Log Only বাটন ব্যবহার করুন** ছোট/পুরনো/একাধিক ফাইল আপলোডের সময় — ইউজার বিরক্ত হবে না, অথচ নতুন মুভি লাইব্রেরিতে যুক্ত হবে। **বড় রিলিজের সময়ই শুধু Broadcast & Log** দিন — যত কম ব্রডকাস্ট, তত বেশি খোলা হয়।
5. **ব্যানার ইমপ্রেশন ফ্রি ইনকাম** — ব্যানার অ্যাপ খুললেই চলে, ইউজারকে বিরক্ত করে না। এটা বাড়াতে ইউজারদের অ্যাপে যত টানবেন (ডিপ-লিংক এখন সেটাই করে), তত ব্যানার ভিউ।
6. **VIP প্যাকেজ প্রমোট করুন** — অ্যাড মোডালে এখন লেখা আছে "VIP হলে কোনো অ্যাড দেখতে হবে না"। যারা বিরক্ত, তারাই VIP কিনবে — অ্যাড ইনকাম + VIP ইনকাম দুটোই আসবে।
7. **১৮+ ট্রাফিক আলাদা লিংকে** — ১৮+ কনটেন্টের CPM অনেক হাই। `/addadultlink` দিয়ে ওই ক্যাটাগরির জন্য আলাদা লিংক রাখুন, তাহলে মেইন লিংকের কোয়ালিটি নষ্ট হবে না।
8. **চ্যানেলে পিন করুন** নতুন বড় রিলিজ — পিন করা পোস্ট সবাই দেখে, ভিউ কয়েকগুণ বাড়ে।
