# 🎬 MovieBoxx Bot (Final Updated Version)

আপনার অরিজিনাল বটের উপরে সবগুলো ফিক্স ও নতুন ফিচার বসানো হয়েছে। নিচে সব পরিবর্তনের তালিকা।

---

## ✅ যা যা ফিক্স হয়েছে

### ১. লগ চ্যানেলে পোস্ট হচ্ছিল না (সবচেয়ে বড় বাগ)
- **আগে:** পোস্ট ফেইল হলে `except: pass` দিয়ে চুপচাপ ঢুকে পড়তো — আপনি বুঝতেই পারতেন না
- **এখন:** লগ পোস্ট ফেইল হলে আপলোডের মেসেজেই **সঠিক কারণ দেখাবে** (চ্যানেল নেই / বট অ্যাডমিন না / রেট-লিমিট)
- `/setlogchannel -1001234567890` — লগ চ্যানেল রানটাইমে বদলানোর কমান্ড
- `/testlog` — লগ সিস্টেম টেস্ট করুন, ফেইল হলে কারণ + সমাধান দেখাবে
- ⚠️ **বটকে অবশ্যই লগ চ্যানেলে Admin বানাতে হবে**, নাহলে পোস্ট যাবে না (এখন এরর দেখাবে)

### ২. Watch Now মরা বাটন
- `APP_URL` env সেট না থাকলে আগে ভুল/খালি URL-এর মৃত web_app বাটন বসত
- এখন APP_URL না থাকলে বাটনটা বসেই না (ক্র্যাশ/মৃত বাটন নেই)

### ৩. অ্যাড টাইমার লুপ
- **আগে:** অ্যাডে প্রতিবার রি-ক্লিক করলে টাইমার রিসেট হয়ে ইউজার আটকে যেত
- **এখন:** **প্রথম ক্লিকেই ঘড়ি চালু** — রি-ক্লিক করলে টাইমার চলতেই থাকে, মেসেজে দেখায় "আরো X সেকেন্ড অপেক্ষা করুন (রাউন্ড r/N)"
- সময় পূর্ণ হলেই আনলক — আর কোনো অসীম লুপ নেই

### ৪. আপলোড ফ্রিজ / 409 Conflict
- বট এখন **Webhook মোডে** চলে (APP_URL সেট থাকলে) — Render-এ ডাবল-ইনস্ট্যান্স হলে মেসেজ হারানো/ফ্রিজ বন্ধ
- APP_URL না থাকলে আগের মতো পোলিং মোডেই চলবে (লোকাল টেস্টের জন্য)

## ✨ নতুন ফিচার

### ৫. ৩-বাটন আপলোড সিস্টেম
ক্যাটাগরি সিলেক্টের পর এখন ৩টা অপশন:
- **📝 Log Only (No Broadcast)** — শুধু লগ চ্যানেলে পোস্ট হবে
- **🚀 New Movie (Broadcast & Log)** — লগ + সব ইউজারকে ব্রডকাস্ট
- **➕ Add File Only (No Broadcast)** — শুধু ওয়েব অ্যাপে ফাইল

### ৬. লগ পোস্টে Watch Now → সাথে সাথে ফাইল
- লগ চ্যানেলের পোস্টের Watch Now বাটনে চাপলে ইউজার বটে `/start open_<movie_id>` পায়
- বট সাথে সাথে **সেই মুভির সব কোয়ালিটির ফাইল** পাঠিয়ে দেয় (VIP/অটো-ডিলিট/প্রোটেক্ট লজিক সহ)

### ৭. নতুন ইউজার গেট (Web App)
- নতুন ইউজার অ্যাপ খুললে গেট মোডাল আসবে — সর্বশেষ মুভির নামসহ
- অ্যাড পাস করলে "বটে যান" বাটন → সরাসরি মুভি ফাইল বটে পেয়ে যাবে
- একবার পাস করলে আর আসবে না (localStorage)

### ৮. অ্যাড সিস্টেম আপগ্রেড
- `/setadcount N` (1-5) — ডাউনলোডের আগে **Nটি বিজ্ঞাপন রাউন্ড** (আগে এই সেটিং কাজই করত না, এখন ওয়েব অ্যাপ পড়ে)
- `/setadwait 10` — প্রতি রাউন্ডে অ্যাডে কত সেকেন্ড থাকতে হবে (5-120)
- **৩০ মিনিট রোটেশন** — অ্যাড লিংক প্রতি ৩০ মিনিটে বদলায় (সার্ভার-সাইড, সব ইউজারে একই লিংক)
- **ব্যানার অ্যাড (Adsterra):** 300x250 হোম স্পন্সর কার্ডে + অ্যাড মোডালে, 320x50 ডাউনলোড পপ-আপে, ১৮+ মুভিতে আলাদা অ্যাডাল্ট ব্যানার
- **স্পন্সর কার্ড** হোম পেজে (Trending-এর নিচে)
- সেটিংসে লিংক না থাকলে কোডে দেওয়া ডিফল্ট লিংকগুলো ব্যবহার হবে (`/addlink` দিয়ে নিজের লিংক বসালে সেটাই চলবে)

### ৯. অন্যান্য
- `/setbcastdel 24` — ব্রডকাস্ট নোটিফিকেশন কত ঘণ্টা পর অটো-ডিলিট হবে (ডিফল্ট ২৪)
- একই নামে আরেকটি ফাইল অ্যাড করলে জানাবে — ওয়েব অ্যাপে একই কার্ডে নতুন কোয়ালিটি হিসেবে দেখাবে
- self-ping এখন নিজের APP_URL পিং করে

## ⚙️ Environment Variables (Railway / Render)

| Variable | কী দেবেন |
| --- | --- |
| `BOT_TOKEN` | BotFather-এর টোকেন |
| `MONGO_URI` | MongoDB Atlas কানেকশন স্ট্রিং |
| `ADMIN_ID` | আপনার Telegram ID (সংখ্যা) |
| `APP_URL` | আপনার অ্যাপের পাবলিক URL (যেমন `https://xxx.up.railway.app`) — **webhook মোডের জন্য দরকার** |
| `ADMIN_PASS` | অ্যাডমিন প্যানেল পাসওয়ার্ড (ডিফল্ট: admin123 — **অবশ্যই বদলান**) |
| `LOG_CHANNEL_ID` | লগ চ্যানেল আইডি (optional — `/setlogchannel` দিয়েও সেট করা যায়) |
| `WEBHOOK_SECRET` | optional — না দিলে অটো জেনারেট হয় |

> নোট: `main.py`-এর একদম উপরে `BOT_USERNAME = "bdlatestmovie_bot"` — আপনার বটের ইউজারনেম এটা না হলে এখানে বদলে নিন (লগ পোস্টের Watch Now লিংক এটা দিয়েই তৈরি হয়)।

## 🚀 Deploy

1. এই ৪টা ফাইল GitHub রিপোতে আপলোড করুন (পুরনো `main.py` রিপ্লেস করুন)
2. Railway/Render-এ Environment Variables সেট করুন
3. Deploy — লগে `Webhook set: ...` দেখলে বুঝবেন webhook মোডে চলছে
4. বটকে লগ চ্যানেলে **Admin** করুন, তারপর `/testlog` দিয়ে টেস্ট করুন
