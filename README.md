# 🎬 Movie Box Bot — v4 (আর্নিং বুস্ট + বাগফিক্স)

টেলিগ্রাম মুভি বট + Web App (Mini App) — অ্যাড মনিটাইজেশন (Adsterra + Monetag), ৩-বাটন আপলোড সিস্টেম, ব্রডকাস্ট ডিপ-লিংক এবং আর্নিং বুস্ট ফিচারসহ সম্পূর্ণ ভার্সন।

---

## 🆕 v4-এ যা যা নতুন/ঠিক হয়েছে

### 💰 ১) অ্যাড ১০-সেকেন্ড এনফোর্সমেন্ট (ইউজার ঠগাতে পারবে না)
- ইউজার অ্যাডে ক্লিক করে **আগে ফিরে এলে** দেখাবে: **"⛔ আপনি সম্পূর্ণ ১০ সেকেন্ড অ্যাডটা দেখেন নি! আরো X সেকেন্ড বাকি — আবার অ্যাডে ক্লিক করে সময় পূরণ করুন।"**
- বাকি সময় পূরণ না হওয়া পর্যন্ত **আবার আবার অ্যাডে ক্লিক করতেই হবে** — প্রতিটা রি-ক্লিক = নতুন অ্যাড ইমপ্রেশন = বাড়তি আর্নিং
- পুরো সময় দেখার আগে আনলক হবে না (রাউন্ড কাউন্টও হবে না)

### 🔥 ২) Watch Now গেট এখন সবার জন্য
- আগে শুধু নতুন ইউজার দেখতো — এখন **পোস্টের Watch Now চাপলে সবাই আগে মুভির নাম + স্পন্সর অ্যাড** দেখবে
- অ্যাডে ক্লিক করে ফিরে এসে আবার চাপলে ফাইল/ডাউনলোড পেজে যাবে — এই ইউনিক টেকনিকে আর্নিং বাড়বে

### 🎁 ৩) নতুন ইউজার = বট থেকে সাথে সাথে ফাইল
- নতুন ইউজার (আগে কখনো ডাউনলোড করেনি) গেট পাস করলে বাটন হয় **"🤖 বটে যান — সাথে সাথে ফাইল নিন"**
- বটে গিয়ে **/start করার সাথে সাথেই** বট নিজে থেকে ওই মুভির সব কোয়ালিটির ফাইল পাঠিয়ে দেয় (`/start open_<id>` পেলোড টেকনিক)
- ফাইল পাওয়ার পর সে আর "নতুন" থাকে না — পরেরবার থেকে অ্যাপে সাধারণ ফ্লো

### 🖥️ ৪) ডাউনলোড পপ-আপ নতুন ডিজাইন
- **ব্যানার অ্যাড ডাউনলোড বাটনের উপরে** উঠে গেছে (আগে নিচে ছিল)
- **স্পন্সর কার্ড ছোট** — মুভি-কার্ড সাইজের কমপ্যাক্ট কার্ড (থাম্বনেইল + এক লাইন টেক্সট)
- **"নিশ্চিন্তে — এমনিতে ক্লিক করুন" বাদ!** এখন কিউরিওসিটি হেডলাইন, প্রতিবার র‍্যান্ডম বদলায়:
  - 🔥 ভেতরে যা আছে, দেখলে চমকে যাবেন!
  - 😱 এই ভুলটা ৯০% মানুষই করে — আপনি?
  - 🤫 সবাই লুকিয়ে রাখে এই ট্রিকটা!
  - 💰 এক ক্লিকে যা পাবেন, ভাবতেও পারবেন না!
  - ⚡ সবার আগে জানুন — এখনই দেখুন!
  - 🎁 আজকের বিশেষ সাপ্রাইজ ভেতরে অপেক্ষা করছে!

### 📺 ৫) লগ চ্যানেল এখন আরও রিলায়েবল
- env-এ `LOG_CHANNEL_ID` **বা `LOG_CHANNEL`** — যেকোনো নামে সেট থাকলেই ধরবে
- **অটো-সেট:** বট যে চ্যানেলে অ্যাডমিন, সেখানে কেউ পোস্ট করলে এবং লগ চ্যানেল আনসেট থাকলে ওই চ্যানেলটাই অটো-সেট হয়ে যায়
- ফেইল হলে **আসল এরর** দেখায় (বট অ্যাডমিন না / চ্যানেল আইডি ভুল) + সফল হলে ক্লিকযোগ্য পোস্ট লিংক
- Watch Now বাটনের ফলব্যাক: ওয়েব অ্যাপ URL না থাকলে বট ডিপ-লিংক (`t.me/bot?start=open_id`) — ক্লিকেই বট ফাইল দেয়

### v3-এ ঠিক হয়েছিল (সব এখনো অ্যাক্টিভ)
- Watch Now ডিপ-লিংক (?open= → সরাসরি ওই মুভি) + `/setwebapp`
- আপলোড ফ্রিজ ফিক্স (ভুল ইনপুটে বট সবসময় জবাব দেয়, যতবার খুশি আবার লেখা যায়)
- রিলিজ সাল / ক্যাটাগরি আলাদা ফিল্ড + ক্যাপশনে আলাদা লাইন (`📅 রিলিজ: 2024` / `🏷️ ক্যাটাগরি: ...`)
- Render-এ webhook মোড (ডাবল-ইনস্ট্যান্স মেসেজ-হারানো বন্ধ)
- ব্রডকাস্ট অটো-ডিলিট রিস্টার্টেও বাঁচে + রেট-লিমিট + ব্লক-ইউজার ডিটেক্ট
- InitData HMAC ভেরিফিকেশন + সার্ভার-সাইড আনলক চেক

## 📦 ডিপ্লয় (Render)

**Environment Variables:**

| Key | মান | জরুরি? |
| --- | --- | --- |
| `BOT_TOKEN` | BotFather টোকেন | ✅ |
| `MONGO_URI` | MongoDB Atlas URI (`mongodb+srv://...`) | ✅ |
| `ADMIN_IDS` | আপনার Telegram আইডি | ✅ |
| `LOG_CHANNEL_ID` / `LOG_CHANNEL` | লগ চ্যানেল আইডি (ঐচ্ছিক — `/setlogchannel` দিয়েও হয়, অটো-সেটও হয়) | ⬜ |
| `WEBAPP_URL` | ওয়েব অ্যাপ URL (ঐচ্ছিক — Render URL অটো-ধরা পড়ে) | ⬜ |

**Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`

**MongoDB Atlas:** ফ্রি M0 ক্লাস্টার → Network Access-এ `0.0.0.0/0` → connection string `MONGO_URI`-তে।

### ✅ ডিপ্লয়ের পর চেকলিস্ট (৩ মিনিট)
1. বটে `/start` → অ্যাপ বাটন আসবে
2. `/setlogchannel` → বট টেস্ট পোস্ট করবে → **লিংকে ক্লিক করে নিজের চোখে দেখুন**
3. BotFather → `/mybots` → Bot Settings → **Menu Button** → Render URL দিন (Watch Now বাটন কাজ করার জন্য)
4. একটা মুভি পোস্ট করুন: ফাইল → কোয়ালিটি → টাইটেল → সাল → পোস্টার → ক্যাটাগরি → ৩ বাটন
5. পোস্টের Watch Now চাপুন → গেট (নাম + অ্যাড) → অ্যাডে ক্লিক → ফিরে এসে আবার চাপুন → ফাইল/ডাউনলোড পেজ

## 🛠️ আপলোড ফ্লো (৩-বাটন সিস্টেম)
মুভির ফাইল পাঠান (একাধিক কোয়ালিটি: ৪৮০p/৭২০p/১০৮০p/৪K) → টাইটেল → রিলিজ সাল → পোস্টার (স্কিপযোগ্য) → ক্যাটাগরি (মাল্টি-সিলেক্ট) → তারপর:
- **📝 Log Only** — DB + লগ চ্যানেল (ব্রডকাস্ট নয়)
- **🚀 New Movie (Broadcast & Log)** — DB + লগ + সব ইউজারে নোটিফিকেশন (Watch Now বাটনসহ, অটো-ডিলিট শিডিউলড)
- **➕ Add File Only** — শুধু DB/অ্যাপে
- যেকোনো ধাপে `/cancel`

## 💰 অ্যাড সিস্টেম সামারি
- **৩০ মিনিট অটো-রোটেশন:** সাধারণ ৩ লিংক (Adsterra ×২ + Monetag ×১) + ১৮+ ২ লিংক (auctionr ×২) — প্রতি ৩০ মিনিটে অ্যাক্টিভ লিংক বদলায় (সার্ভার-সাইড, `/ads` দিয়ে দেখুন)
- **স্পন্সর কার্ড:** হোম ফিডে প্রতি ৬ মুভিতে + ডাউনলোড পপ-আপে (ছোট কার্ড, কিউরিওসিটি হেডলাইন)
- **ব্যানার ×৩:** হোম ৩০০×২৫০, ডাউনলোড পপ-আপে (বাটনের উপরে) ৩২০×৫০, ১৮+ মুভিতে অ্যাডাল্ট ব্যানার ৩০০×২৫০
- **১০-সেকেন্ড এনফোর্সমেন্ট** + মাল্টি-রাউন্ড (`/setadcount`)
- **গেট ফর অল + নতুন ইউজার বট-ইনস্ট্যান্ট-ফাইল**
- **VIP = অ্যাড ছাড়া ডাউনলোড**
